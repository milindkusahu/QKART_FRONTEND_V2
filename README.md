# QKart E-commerce Platform

QKart is a modern e-commerce application built with React, offering a seamless shopping experience with features like product browsing, cart management, and secure checkout.

![QKart Component Architecture](https://raw.githubusercontent.com/milindkusahu/QKART_FRONTEND_V2/refs/heads/main/public/demo/user-flow.png)

## 🌟 Live Demo

- Checkout: [https://qkart-frontend-opal-psi.vercel.app/](https://qkart-frontend-opal-psi.vercel.app/ "QKart Demo")

## 🚀 Features

- **Authentication**

  - User registration and login
  - Form validation and error handling
  - Local storage for persistent login

- **Product Management**

  - Dynamic product loading
  - Search functionality with debouncing
  - Responsive grid layout

- **Shopping Cart**

  - Add/remove items
  - Quantity adjustment
  - Real-time price calculation

- **Checkout Process**

  - Multiple address management
  - Order summary
  - Payment integration

---

## 🛠️ Tech Stack

- **Frontend**

  - React.js
  - Material UI
  - React Router v6
  - Axios for API calls
  - Vite for build tooling

- **Features**

  - Responsive Design
  - Debounced Search
  - Protected Routes
  - Token-based Authentication
  - Local Storage Integration

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/milindkusahu/QKART_FRONTEND_V2.git
```

### 2. Install dependencies

```bash
cd QKART_FRONTEND_V2
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```
